Privacy & implementation notes:
  • Direct fetch (no proxy) is preferred for privacy. Many sites disallow cross-origin fetches; when that happens the script falls back to AllOrigins.
  • Using a public proxy sends the target page URL to that service, and may expose page contents to that proxy.
  • If you require full privacy, run your own small CORS-proxy (e.g., a tiny server you control) and set PROXY_RAW accordingly, or run this tool locally using a browser extension or Node script.
  • Sites with X-Frame-Options or other protections may still block embedding; this script only fetches raw HTML and parses it, so embedding is not required.
