Privacy & implementation notes:
  • The Netlify server-side endpoint is preferred because browser CORS blocks many websites. Direct browser fetch and AllOrigins are fallback options.
  • Using a public proxy sends the target page URL to that service, and may expose page contents to that proxy.
  • For strict privacy, host the server-side function yourself or run this tool locally; do not use a public proxy.
  • Sites with X-Frame-Options or other protections may still block embedding; this script only fetches raw HTML and parses it, so embedding is not required.
